# UnoCode Desktop demo workspace

The editor rendering this file is the **same C** that runs on a bare-metal PC
under UnoDOS - recompiled for the desktop over a small SDL2 shim.

- `HELLO.C` - C highlighting
- `TOOL.PY` - Python highlighting
- `DATA.JSN` - JSONC, the config dialect every settings file here uses

Try: `Ctrl+Shift+P` for the command palette, `Ctrl+P` to jump to a file,
`Ctrl+F` to find, `Ctrl+\`` for the terminal.
